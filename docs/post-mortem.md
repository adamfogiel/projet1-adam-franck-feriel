# Post-mortem — Rappels de produits de consommation

À écrire collectivement après la soutenance (livrable L5, modèle de l'annexe C).
Il porte sur les processus et les décisions, pas sur les personnes : on ne
cherche pas de coupable.

Deux à trois pages.

## 1. Rappel de l'objectif

Ce qui avait été promis au commanditaire, et ce qui a été livré.

## 2. Chronologie

Les événements marquants, datés, jalon par jalon.

## 3. Points de friction

Pour chacun : symptôme observé, cause identifiée, ajustement effectué.
Poser « pourquoi ? » jusqu'à atteindre une cause sur laquelle l'équipe peut
agir — un symptôme n'est pas une cause.

## 4. Ce qui a fonctionné

Pratiques à conserver.

## 5. Anomalies de données et de code corrigées

Renvoi vers `docs/anomalies.md` et vers les pull requests concernées.

## 6. Enseignements pour le Projet 2

Trois à cinq actions concrètes, formulées comme des engagements.
